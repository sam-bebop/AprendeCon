# PrendeCon Final Features Walkthrough (Tutor Dashboard & Cuatrimestre Filter)

We have successfully implemented the final features requested:
1. **Tutor Dashboard ("Asesorías como Tutor")**: In **Mis tutorías (Screen 9)**, users with "Modo Tutor" enabled can switch between "Como Alumno" (sessions they booked) and "Asesorías como Tutor" (sessions booked by students for them).
2. **Cuatrimestre Filtering**: In **Búsqueda / Filtros (Screen 5)**, students can filter tutors by specific cuatrimestres (*1°, 3°, 4°, 6°, 8°*).
